周日。傍晚开始动手，把两组B站下载的音视频素材合并成完整视频，上传到 GitHub 的 QQ-Mail 仓库。节奏松弛，像水豚泡温泉一样不慌不忙地收了两件小活。

🎬 两次音视频合并

第一组来源是牛津年度词汇相关的视频画面和独立音频。用 ffmpeg 无损复制视频流、替换音轨，输出为"2025牛津年度词汇：愤怒诱饵.mp4"（1080×1920 竖屏，2分3秒）。

第二组是"苹果Logo"相关素材：视频 1280×720 横屏 h264、时长近6分钟，音频是独立 AAC 轨。同样用 -c:v copy -c:a aac -map 0:v:0 -map 1:a:0 的方式合并，输出 5分56秒。

两次操作流程一致：确认文件存在 → ffmpeg 合并（视频流 copy 零损耗） → 验证 → 上传。

☁️ GitHub 上传与一个小插曲

第一次上传"愤怒诱饵.mp4"时，手动拼的 URL 编码把"诱饵"编成了"险孺"——%E8%AF%B1 和 %E9%99%A9 只差一个字节，路径就错到位了。发现后走 GitHub API 的 DELETE+PUT 两步修正，第二次改用 PowerShell 的 [System.Uri]::EscapeDataString() 自动编码，不再手拼。

"苹果Logo.mp4"的上传一次成功，文件名稳妥。

上传过程中遇到 git 全局代理 127.0.0.1:7890（Clash）未启动的问题，Git 命令全部走不通。最后绕过 git，直接用 curl + GitHub API 的 PUT contents 接口，base64 传输文件体。12MB 和 6MB 的文件分别成功推送到 NewtNorlly/QQ-Mail 仓库的 2025/ 目录下。
