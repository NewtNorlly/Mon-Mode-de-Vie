🐛 Debugging / Fixing Pitfalls

Today's repeated format fine-tuning is worth recording (quite a few lessons):

  1. Inconsistent file naming — some file names used spaces instead of underscores, which tripped up the sorting script at first
  2. Encoding handling when generating summaries — Node.js ran into problems multiple times with Chinese paths/content, and it stabilized after switching to a full file script
  3. Backslash escape disaster — when replacing ____ → \_\_\_\_, repeated replacements left stray backslashes, which were finally cleaned up with a regex scan
  4. Escaping damage inside tables — the ____ inside tables did not need escaping, but an earlier global replacement processed them too and they were later fixed separately
  5. Markdown --- residue — there were 369 occurrences of --- left unreplaced in the answer explanations file (from the separators in the original card content)
  6. Inconsistent chapter title format — three formats were mixed together and unified to 'Chapter X 〈chapter name〉'
